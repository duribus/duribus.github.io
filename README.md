# 오늘의 두리버스

강원대학교 교내 순환버스(두리버스)의 **오늘 시간표와 다음 버스까지 남은 시간**을 한눈에 보여주는 모바일 웹앱입니다.

👉 **사용하기: https://duribus.github.io/**

로그인이나 앱스토어 없이 휴대폰 브라우저로 열면 바로 쓸 수 있고, "홈 화면에 추가"를 하면 앱처럼 설치됩니다.

## 왜 만들었나

학교 홈페이지의 두리버스 안내는 PC용 표로만 되어 있어서, 길에서 휴대폰으로 "다음 버스가 언제 오지?"를 확인하기 어려웠습니다.
타는 정류장만 고르면 오늘 운행 여부와 다음 버스 시간이 바로 보이도록 만들었습니다.

## 기능

- **다음 버스**: 고른 정류장의 다음 버스 시간과 남은 시간(분 단위), 오늘 남은 시간 목록
- **도착지·방향**: "어디로 가세요?"에서 도착 정류장을 고르면 그 방향 버스만, 도착 시간·소요 시간과 함께 표시. 한 바퀴에 두 번 서는 정류장(새롬관·미래도서관·미래광장)은 방향별로 걸러 보기
- **노선**: 순환 노선을 세로로 보여주고, 지금 운행 중인 버스의 대략적인 위치 표시(시간표 기준 추정)
- **시간표**: 회차별 정류장 도착 시간, 다른 날짜 미리보기
- **운행일 판단**: 주말·공휴일·공식휴강일·방학에는 "운행 없음" 표시
- **설치·오프라인**: PWA로 홈 화면 설치, 인터넷이 없어도 시간표 확인
- **가까운 정류장**: 위치 권한을 허용하면 내 위치에서 가장 가까운 정류장을 자동 선택(위치는 기기 안에서만 계산, 저장·전송 안 함)
- 마지막으로 고른 정류장과 탭을 기억

## 의견 받기

- 화면 아래 "오늘 시간표, 실제와 맞았나요?" 버튼(맞았어요/달랐어요)으로 정확도를 익명 집계합니다.
- "의견 보내기"는 구글 폼으로 연결되어 불편한 점·바라는 기능을 익명으로 받습니다.

## 데이터

- 출처: [강원대학교 교통안내 페이지](https://www.kangwon.ac.kr/ko/conts/198/web.do)
- 현재 반영: 2026학년도 2학기 (2026. 9. 1. ~ 12. 21., 월~금 하루 10회)
- 학교 페이지를 매주 확인해 시간표가 바뀌면 이 저장소의 `index.html`을 업데이트합니다.
- 실제 운행은 교통 상황에 따라 달라질 수 있으며, 정확한 정보는 학교 공지를 우선합니다.

## 사용 통계

[GoatCounter](https://www.goatcounter.com/)로 익명 통계(방문 수, 정류장·탭 사용, 설치 여부)를 수집합니다. 쿠키와 개인정보는 저장하지 않습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면과 시간표 데이터 (`STOPS`, `DEPS`, `START`, `END`, `OFF`) |
| `manifest.webmanifest` | 홈 화면 설치 정보(이름, 아이콘, 색) |
| (외부) Leaflet · OpenStreetMap | 지도에서 정류장 선택 (지도를 열 때만 불러옴) |
| `sw.js` | 오프라인 저장(서비스 워커) |
| `icon-*.png`, `apple-touch-icon.png` | 앱 아이콘 |
